# 💻 practicaUT6

Aplicación web desarrollada como práctica académica utilizando principalmente **PHP y CSS**.

El proyecto consiste en una pequeña plataforma de gestión de usuarios y configuración de ordenadores. Los usuarios pueden crear su propio ordenador seleccionando diferentes componentes de hardware a partir de los listados disponibles en la aplicación.

## 🚀 Funcionalidades

### 👤 Gestión de usuarios

* Registro de nuevos usuarios.
* Inicio de sesión.
* Gestión de usuarios mediante diferentes permisos.
* Sistema de usuarios administradores.

### 🖥️ Montaje de ordenadores

Cada usuario puede configurar su propio ordenador seleccionando un componente de cada categoría:

* 🧩 Placa base
* 🖥️ Caja
* 💾 Disco duro
* ⚙️ Procesador
* 🧠 Memoria RAM
* 🎮 Tarjeta gráfica

Los componentes se seleccionan a partir de los listados disponibles en la aplicación.

### 🔎 Filtrado y ordenación

Los listados de componentes permiten localizar los productos mediante diferentes opciones de:

* Filtrado.
* Ordenación.
* Búsqueda y selección entre los componentes disponibles.

Esto facilita la configuración del ordenador según las características de los componentes.

### 🛡️ Funciones de administrador

Los usuarios con permisos de administrador disponen de funcionalidades adicionales:

* Eliminar usuarios.
* Exportar el listado de usuarios a un archivo **JSON**.
* Añadir nuevos componentes.
* Eliminar componentes.
* Administrar los componentes disponibles en las diferentes categorías.

## 🛠️ Tecnologías utilizadas

* **PHP** — Lógica de la aplicación y gestión de usuarios y componentes.
* **CSS** — Diseño y estilos de la aplicación.

El proyecto se desarrolló utilizando principalmente PHP, acompañado de un único archivo CSS para los estilos de la interfaz.

## 📂 Estructura general

El proyecto está organizado en diferentes archivos PHP encargados de gestionar las distintas partes de la aplicación, incluyendo:

* Gestión y autenticación de usuarios.
* Configuración del ordenador.
* Listados de componentes.
* Filtrado y ordenación.
* Funciones de administración.
* Exportación de usuarios a JSON.

## 🎯 Objetivo del proyecto

El objetivo de esta práctica era desarrollar una aplicación web funcional capaz de gestionar usuarios y permitirles interactuar con un catálogo de componentes para crear una configuración personalizada de ordenador.

Además, se implementaron diferentes permisos para separar las funcionalidades disponibles para usuarios normales y administradores.

## 📌 Estado del proyecto

**Proyecto académico finalizado.**

El proyecto se conserva como muestra de aprendizaje y experiencia práctica con **PHP, gestión de usuarios, administración de datos y desarrollo web**.
